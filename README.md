# B2C Freelance Platform

Полнофункциональная платформа для фрилансеров и заказчиков с GitHub OAuth, Escrow системой, AI поддержкой и рейтингами.

## 🚀 Возможности

- ✅ Авторизация через GitHub OAuth
- ✅ Escrow система с динамической комиссией (0.5% - 1%)
- ✅ Система рейтингов с защитой от мошенничества
- ✅ Блокировки пользователей и апелляции
- ✅ AI Support (FAQ → AI → Оператор)
- ✅ Модерация и разрешение споров
- ✅ Блокировка по hardware fingerprint

## 🛠 Технологии

**Backend:**
- Node.js + Express
- PostgreSQL
- Redis
- Passport.js (GitHub OAuth)
- JWT

**Frontend:**
- React + TypeScript
- Tailwind CSS
- Zustand (state management)
- React Query

**DevOps:**
- Docker & Docker Compose
- GitHub Actions (CI/CD)
- Prometheus & Grafana (мониторинг)
